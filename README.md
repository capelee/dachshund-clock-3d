# 臘腸狗時鐘 3D 組裝

以3mm壓克力刀線建立的互動幾何試組模型，可選取零件、移動、旋轉、組合、拆解、平鋪與切換透明檢視。

## 使用

開啟 GitHub Pages 網址即可使用，不需要安裝或登入。介面為圖示，滑鼠停留可看操作提示。

## 模型範圍

僅供幾何與外觀檢視，沒有重力或碰撞阻擋，不能取代同材試片與實體裝配。壓克力厚3mm。時鐘標稱外尺寸88×38×21mm，細部依照片近似，非原廠CAD。
